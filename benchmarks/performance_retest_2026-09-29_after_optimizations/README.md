# 2026-09-29 优化后全量性能复测

本轮重建当前含未提交优化的工作树，串行执行现有基准及新增优化专项。所有程序正常退出；固定校验值、逐轮稳定性及外部题答案核对通过。下文保留发现的变慢项，不把全套运行完成等同于全部性能目标达标。

## 主要结论

- 综合负载的 TX 进程墙钟中位数从优化前 481.81 ms 降至 156.34 ms，减少 67.6%；本轮采样工作集峰值中位数约 8.05 MiB。
- 模块审计中，`dictionary_contains` 从 3.740 降至 0.363 ms，`cancel_status` 从 4.031 降至 0.495 ms，`queue_push_pop` 从 12.192 降至 1.290 ms。综合负载的低命中 map 从 21.829 降至 2.453 ms。
- 语言特性仍有变慢项：`virtual_interface` 为 2.210 → 3.679 ms（+66.5%），`class_operator` 为 1.110 → 2.110 ms（+90.1%），`array_padded` 为 0.030 → 0.178 ms（+493.3%，绝对增加 0.148 ms）。这是跨轮候选回退，尚未隔离代码、布局及机器状态因素，不自动归因为本次某一项优化。
- 同轮校准中，字面量格式化仍为 GCC C++ 的 8.44 倍，动态格式化为 5.91 倍，短/长文本 serde 为 14.12/6.18 倍。容器查询大多已经低于 5 倍，但不能据此宣布所有性能目标完成。
- 局部解析和完整结果分开看：局部成功/失败专项为 0.974/1.016 ms，完整结果专项仍为 162.179/191.778 ms。综合程序中的局部解析收益不能替代完整结果路径的结论。
- 两道外部题 TX 普通程序通过 `mini-filesystem` 44/44、`not-yet-on-stage` 45/45 正式数据；五语言计时输出也逐次与正式答案一致。
