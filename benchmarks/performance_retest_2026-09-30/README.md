# 2026-09-30 全量性能复测

完整 ≥3× 筛选见 [差距清单](gaps.md)及[机器可读结果](gaps.json)。倍率为本轮 TX 中位耗时除以参考语言中位耗时，非相对上一轮的退化倍数。

- 最大的语言特性倍率：析构 20.44×、循环 GC 20.23×、深拷贝 9.70×、递归 9.02×、运行时类型转换 8.47×（C++ 对照）。循环 GC 的 C++ 实现只处理单节点自环，深拷贝只复制已知形状，这两项不能解释为通用算法的等价性能差距。可变参数展开的 C++ 侧也不执行 TX 的动态实参绑定。
- 综合同轮四语言对照：短文本 serde 11.80×、字面量格式化 8.64×、动态格式化 6.10×、长文本 serde 5.64×、字面量/动态编码 5.58×/5.42×、文本键字典查询 4.35×。这些项目在另外的 GCC / clang 校准中也都超过 3×，但具体倍率随采样与参考编译器变化。
- 容器和标准库的其他 C++ 差距：queue 4.60×、随机整数 3.98×（长随机数 3.96×）、迭代快照 3.52×、正则 3.49×、bytes_hex 3.46×、vector_push 3.41×。补偿统计均值对 GCC 为 3.32×、对 clang 为 2.35×，不能沿用旧简单求和参考的 17.20×。
- 仅 clang 校准超过阈值的项目：map_hit_128 4.37×、vector_scan_1k 4.02×、map_hit_8192 3.69×；对应 GCC 校准均低于 3×。
- 外部题对 C++：mini-filesystem 的 fanout-2000 5.94×、random-2000-1 5.57×、moves-2000 4.91×；not-yet-on-stage 的 forced-increasing-max 3.30×。mini-filesystem 正式数据 44/44、not-yet-on-stage 45/45 通过。
- 综合进程墙钟 TX 179.757 ms、C++ 76.968 ms，为 2.34×；这不代表各个子项都低于 3×。

统计边界：test_assert 的 C++ 参考被优化至零耗时，不计算倍率；Java 的 26.02× 也受可消除循环影响，不作为有效热点排名。HTTP 中 TX httpx/requests 约为 Java http_get 的 4.33×/4.39×，但客户端实现与输出名称不同，仅作为端到端观察，不并入等价热点清单。Java deinit 使用显式 close 模拟回调，不是 JVM 确定性析构；语言特性更完整的语义差异见[负载说明](../language_features/README.md)。

优先排查绝对时间和倍率同时较大的结构体运算符、对象释放、深拷贝、文本序列化/编码/格式化，再处理容器和短耗时调用。这里是负载定位，未做 profiler 根因分析。

本轮重建当前工作树，串行执行现有基准及新增优化专项。所有程序正常退出；固定校验值、逐轮稳定性及外部题答案核对通过。下文保留发现的变慢项，不把全套运行完成等同于全部性能目标达标。
