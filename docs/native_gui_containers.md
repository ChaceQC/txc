# 自研容器与画布契约

容器和其内容都属于同一个控件树，不创建系统子窗口。新增控件使用独立静态资源类型；
scroll/split 的内容访问器以及 `add_tab` 返回普通 `native_gui_panel`，现有布局和控件可直接嵌套。
关闭外层容器会递归关闭内容；隐藏的页不参与命中、焦点遍历或动画。

- 滚动容器：水平/垂直方向分别启用，内容自然尺寸决定可滚动范围；滚动条占用视口空间。
  鼠标滚轮优先交给最内层可滚动内容，到边界后向祖先传递；Shift+滚轮水平滚动。
  滑块支持捕获拖动，轨道点击翻页。容器聚焦时方向键、PageUp/PageDown、Home/End 可滚动。
  Tab 能进入视口外的可用子控件，并由内向外自动滚入；滚动后的 IME 候选位置同步更新。
- 页签：页 ID 使用返回面板的稳定 `id`，不使用易变数组下标。仅选中页参与布局；
  左右/Home/End 切换可用页，Ctrl+Tab / Ctrl+Shift+Tab 从页内切换。标题超宽时可横向滚动，
  选中标题自动可见。切换时取消旧页捕获和组合输入，焦点从旧页退回页签；程序 setter 静默，
  用户切换产生 `tab_changed`，`item_id` 是页 ID。
- 分隔器：恰有两个内容面板，可横向或纵向排列，比例在 [0,1] 内，结合内容最小尺寸约束。
  分隔条支持捕获拖动；聚焦后方向键调整 2%，Shift 加速为 10%，Home/End 到两端。
  用户修改产生 `split_changed`，释放鼠标产生 `split_committed`；失去捕获不继续拖动。
- 独立画布：保存有界绘制命令，不在应用每一帧反复要求重建。矩形、椭圆、直线和文本使用
  自研光栅/字体；坐标以画布客户区 DIP 表达，遵循嵌套裁剪与 DPI。指针事件包含局部 `x/y`，
  键盘事件携带 key 和修饰键。`canvas_clear` 清除旧命令并设置背景。

事件扩展 `item_id/column_id/x/y/modifiers`，原有字段与意义保留；ID 保持整数，不经浮点转换。
modifiers 位为 Shift=1、Ctrl=2、Alt=4、Meta=8。程序修改不伪造用户操作通知。

这些是实现和定向验证的契约；双平台运行与真实桌面验收的状态在续接记录中单独列出。
