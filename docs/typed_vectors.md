# 类型化 vector

本轮实现范围：`vector<int>`、`vector<float>`、`vector<bool>`、`vector<str>`。它们在局部变量、函数参数、返回值、结构体与类字段、`.txh` 接口中保持完整静态类型。复合元素向量和类型化哈希容器留待后续扩展，本轮遇到这些类型时应给出编译诊断。

## 类型和构造

- `vector<T>()` 创建空向量；`vector<T>(n, value)` 创建 n 个初值，n 必须为非负 int，value 必须精确匹配 T。
- 向量元素的静态类型为 T；写入和方法参数按静态类型检查，不隐式转换不同基础类型。
- `vector<T>` 是内置参数化类型，不引入用户模板系统。旧 `array`、`dict` 的异构语义保持不变。
- 向量普通赋值、传参、返回和存入字段共享同一容器；`deep_copy` 创建独立容器并保留对象图的共享关系。
- class 中未显式赋值的 vector 字段默认为空向量。
- 向量可放入旧 array、dict 或 any；从 any 恢复向量必须显式 `as vector<T>`，按完整实际类型检查。`vector<T>(array)` 显式复制数组并逐项严格检查；`to_array()` 返回新的异构数组。转换失败不修改源容器。

## 操作

| 操作 | 规则 |
| --- | --- |
| `len(v)`、`v.size()` | 当前有效元素数 |
| `v.capacity()` | 当前容量 |
| `v.reserve(n)` | 保证至少 n 的容量，长度不变 |
| `v.push_back(value)` | 末尾追加，摊还 O(1) |
| `v.pop_back()` | 删除尾元素，空向量报运行错误，无返回值 |
| `v.resize(n, value)` | 增长填充指定值；缩小释放尾元素 |
| `v.clear()` | 清空元素，保留容量 |
| `v.insert(index, value)` | 在 0 到 size 之间插入，O(n) |
| `v.erase(index)` | 删除有效下标的元素，O(n) |
| `v[i]` | int 下标，读写类型为 T，越界时报运行错误 |
| `for item in v` | 捕获容器和初始长度，每次按下标读取当前元素；追加不延长遍历，缩短导致待访问下标越界时报错 |

扩容遵循连续存储与几何增长原则，具体容量增长倍率不属于语言契约。bool 使用字节，不采用位代理。下标表达式与实参从左到右各求值一次；可能改变容器的表达式求值后重新获取数据地址，禁止保存跨扩容的裸元素地址。

## 字符串与内存

vector 的元素区采用 C++23 `std::vector<T>` 管理。整数和浮点数连续存储原生数值；字符串连续存储不可变文本引用，字符串变量和向量间传递共享文本，不逐元素装箱。长度、数据区通过 TX 自有 ABI 暴露，LLVM 不依赖 libstdc++ 的私有布局。普通数值下标读写生成直接 load/store，冷路径负责错误报告与扩容。

本轮所有元素类型都不能形成引用环，向量自身不登记循环 GC；实际分配仍按现有规则触发安全点。字符串引用与外部临时句柄分别管理所有权，错误退出释放根引用，容器销毁释放内部引用，避免提前销毁共享文本。

字符串模块新增 `split_vector(text: str, separator: str) -> vector<str>`；`join` 增加 `vector<str>` 重载。原有 split/array 路径保留，类型化路径不经过中间 array。

## 交付与验证

实现后迁移 mini-filesystem 的节点属性、命令、结果及路径分量，保持其路径解析与 MOVE 规则。验证覆盖四种元素类型、共享与 deep_copy、扩容副作用、跨模块字段、动态边界转换和错误退出；题目检查正式答案并测量五组内部耗时。实现进度与结果在本文件末尾记录。

2026-09-25 已实现上述范围，正式工具链位于 `tx/`。类型化容器不要求局部逃逸分析成立；即使作为函数参数、返回值或字段，也保留原生元素表示。容器在当前复合值 ABI 边界仍以单个共享句柄保存，类型化入口取得稳定的 `vector_view`；元素区不使用 `any`。字段定位和取得容器视图仍有 ABI 调用成本，不能把本轮实现描述为所有复合类型都已采用原生字段布局。

运行 `python scripts/check_vectors.py` 可复现定向验证：15 项正常行为检查、6 种运行错误与析构清理、4 种带源码位置的编译诊断。示例包括跨 `.txh` 返回结构体、函数传入向量、字段重绑定时保持已求值的目标容器、扩容期间别名、共享关系的 deep_copy、字符串清空后保留变量值，以及迭代期间追加。

同一脚本还包含 16 项字符串借用、复合键与 UTF-8 检查。后续字符串优化让向量元素直接复制内部引用，并为只读字符串操作借用稳定的向量元素；需要保存值、经过用户回调或跨越可能修改拥有者的表达式时仍保留拥有型快照。

mini-filesystem 已迁移，普通解与计时解分别通过 44/44 组正式数据。性能结果见 [性能优化记录](mini_filesystem_performance.md#类型化-vector-落地)。暂不支持复合元素 vector、用户泛型、迭代器或类型化哈希容器；这些类型不会退化为隐藏的异构数组。
