# 优化后热点与回退修复

日期：2026-09-29。起点为优化后全量报告对应的工作树和发布包；保留此前未提交修改和历史报告。

## 范围与顺序

1. 优先定位 `not-yet-on-stage` 五组输入、十万元素向量扫描、虚方法和类运算符的回退。对照实际生成的 IR、优化后机器码及同机交替样本；先区分局部数组命中、循环安全点、溢出检查、接收者恢复与代码布局，不以跨轮百分比归因。
2. 完整解析结果：只观察嵌套 error 字段时尽可能延迟对象物化；修改、别名、逃逸与 error 身份保持现有语义。成功和失败分别验证，不能用局部标量结果替代完整字段负载。
3. serde：已知 schema 的字段直接编解码，减少临时字段槽和 std::any 搬运；保留未知字段、重复字段、字段缺失、诊断顺序和失败回退语义。
4. 格式化：分别保留字面量、局部固定模板与函数传入/交替动态模板，优先减少动态参数容器和装箱；不将固定模板成绩称为动态模板收益。
5. 字典遍历、对象生命周期及短文本编码：只有证明键集合稳定时才能缩减快照成本；对象保持共享、析构与错误语义；编码保持严格 UTF-8 验证和现有 bytes 值语义。

## 实施与验证约束

- 修改前冻结 `tx/` 完整包、DLL、源码哈希和相关基准，存入 `tx_build/performance_hotspots/before/`，不覆盖上一轮证据。
- 每个改动对应可指出的生成代码或运行时开销。公开语言及接口不变；ABI 或布局变化必须更新兼容指纹覆盖并整体重建编译器、静态库及三个 TX 桥接对象。
- 定向验证新增优化的逃逸、别名、修改、异常与边界情况；只执行与本次改动直接相关的检查。
- 性能测量串行运行，旧/新程序交替，逐轮核对校验值；保存原始样本和产物哈希。初次使用 1 次预热、5 轮测量，只有分布异常或需要检验新改动时追加。
- 实施、语义验证、同轮收益、仍未解决的热点分别记录，不宣称通用实现已达到特定 C++ 负载的倍率。

## 当前状态

基线已冻结。首批实现针对以下静态证据：

- `used` 的动态局部标量数组优化仍命中，但 `is_none` 与标量读取被 GC 判定当成 any 物化，外层 if 每次执行安全点；动态局部数组写入也未纳入无分配判定。
- 向量扫描已直接读取连续存储，但溢出冷分支使用原操作数，使机器码逐元素保存旧累加值。改为在已确认溢出的分支调用原运算入口的确定溢出常量，保留同种错误与源码位置。
- 固定布局虚调用恢复视图后仍调用原签名适配器，适配器再次恢复视图。增加携带视图的虚表，保留原虚表供原生边界使用；TX 方法与运算符传递已缓存视图。对象描述头纳入既有 ABI 指纹并整体重建。
- 父类视图复用 self 的稳定存储头；GC 虚目标汇总排除不可实例化的接口和抽象类，仍检查所有可实例化派生类型，避免抽象声明使只读虚调用被错误视作可能分配。
- 预编译库不能穷举最终程序新增的派生类，库模式仍保留虚调用后的安全点。

已完成首轮定向实现与成对验证，见[结果、原始样本及剩余问题](../benchmarks/performance_hotspots_2026-09-29/README.md)。外部题、向量扫描、虚调用、只读完整错误字段、动态格式化和受限字典遍历得到改善；serde 收益有限，通用对象生命周期及短文本编码仍未解决。

## 解析结果实施边界

局部 `error = parsed.error` 只有在整个函数内能证明 parsed 与 error 均只读取标量/文本字段、无修改、无其他对象别名和无对象逃逸时，才保存错误枚举。普通文本读取仍返回独立文本值；`len` 直接按同一错误文案的 Unicode 标量计数。只读证明失败时保留原结果与 error 的物化路径，包含 error 修改、结果修改、身份比较、容器保存、回调捕获和返回。字段文案与原错误物化使用同一份定义，避免成功/失败两条路径漂移。

## serde 与动态格式化实施边界

- serde 的已知布局直接填入最终对象，用独立存在位记录重复/缺失字段。JSON 字段名以字符串传递，不先包装 any。编码标量通过 schema 的专用槽位函数，文本与引用字段借用对象内值；未知字段合并与错误后的旧解析路径保留。
- 动态格式化的普通 int/float/bool/str 实参使用栈上参数表，编译器绑定各类型格式化函数。沿用原来的模板缓存、字段解析和错误顺序；实参按源码顺序求值，可能被后续求值改变的文本保持独立持有。展开参数和通用对象继续使用原数组/字典路径。
- 字典循环未使用键，且循环体仅有可证明无容器修改/用户回调的标量操作时，进入循环只读取长度，省去键快照。其他字典循环仍使用原键快照，不能把此优化称为通用无快照遍历。
