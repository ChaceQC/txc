# 静态对象与闭包的内部布局契约

本契约用于性能计划 09–11 及第 14 项，不改变 `.tx` 公开语法、共享引用、初始化或错误规则。

编译器生成只读 `record_type` 描述，以模块解析后的唯一类型符号命名。描述持有字段名称、静态类型、8 字节槽偏移、对齐、可能持有对象的扫描索引，以及类的祖先、虚表和析构表。实例引用描述，不复制名称。类沿用语义分析分配的全程序字段槽，多继承视图共享同一对象，转换不复制字段。

int、float、bool 使用原生固定槽；其他字段使用静态类型已知的引用槽，引用拥有普通运行时值，但不额外登记为独立 GC 根。动态 any 仍保留运行时类型。静态访问先取得对象存储视图，再使用固定偏移；局部视图只能随对象绑定一起更新，不能跨重绑定保留旧地址。标量且不逃逸的局部结构体可以仅分配栈槽；普通赋值和任何身份可观察的对象继续共享堆对象。

静态方法另有携带接收者视图的内部入口，调用方在求值其余实参之前绑定该视图。虚表、析构及原生边界保留原参数签名的适配入口，内部入口仍使用同一个逻辑诊断帧。结构体和类的恢复入口在编译期区分，不先试探其他对象类别。

原生标准库接口拥有的旧式记录在模块加载时明确标记，继续通过原生字段 ABI 访问；用户结构体与类使用新描述。不得依赖文件名猜测布局，也不能把原生对象直接解释为静态槽。serde、deep_copy、打印、GC 必须根据对象描述读取实际字段；复制先登记身份，再填充引用。

`record_field` 包含编译期选定的复制种类，大小为 40 字节。当前 `record_type` 为 144 字节，包含内部析构视图、定型追踪和复制入口。复制标量槽不经过 any 装箱；文本/bytes 直接复制值；结构体、类、数组、字典、类型化向量、容器、迭代器和闭包进入已选定的复制分支。动态 any 和资源字段保留通用分派及资源限制。扫描只访问原描述中的可能对象边，复制仍共用身份表，重复引用不会变成独立对象。

槽位编号、大小与对齐由 `common/slot_layout.hpp` 共享。原生标量结构体采用 256 字节的单对象特化预算，允许超过四个字段；独立函数分析支持标量局部、条件、循环与已证明安全的辅助调用。返回参数自身的结构体函数保留别名，不能生成返回新副本的原生入口。引用字段继续保持原槽位的拥有关系，类身份与复活规则不变。详细实现边界见 [静态执行改造](static_execution_architecture.md)。

现有 `any.字段` 仅允许读取，直接修改会在语义分析时报错。动态读取在边界按实际描述装箱字段；`any as 静态类型` 的校验及共享身份保持，随后可按静态类型修改字段。

TX 函数值的内部入口为 `context + environment + 静态参数`。环境的 code、parent、capture 指针在构造后稳定。原生适配入口在实际调用线程获取 context，不在环境里保存线程上下文。标量 bind 捕获直接存入固定槽，引用捕获保留共享关系，deep_copy 使用同一个图身份表。多层 bind 保留父环境，不跨可能有副作用的捕获求值合并。

堆默认比较器属性只在构造来源、局部绑定和用途均可证明时用于借用。对象元素、自定义比较器或逃逸后失去证明的接收者保持原持有路径。比较全部完成后才移动堆元素；固定路径缓冲容量为 `size_t` 的位数，稳定序号、NaN、比较器重入与错误规则不变。

这些描述、稳定头、槽大小及生成代码纳入包兼容指纹；发布包必须整体重建编译器、标准库与三个 TX 桥接对象。
