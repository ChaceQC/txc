# 自绘 GUI 剩余工作与验收边界

更新：2026-10-03。以 [完整版契约](native_gui_full_plan.md) 为范围依据，
以 [实施记录](native_gui_completion.md) 的具体证据区分实现、自动验证和人工验收。

## 已交付的本轮能力

共享命令、快捷键、自绘菜单/上下文菜单、工具栏/状态栏、模态 owner、自绘消息框、
Windows Shell/Linux Portal 文件与目录选择、系统/高对比主题、字号/缩放和 UIA/AT-SPI
已接入公共控件与直接静态 ABI。普通/ThinLTO 和系统辅助客户端的本地定向验证通过。
这不表示全部 GUI 或所有辅助技术扩展接口已经完成。

## 尚缺的实现

| 工作包 | 剩余内容 |
| --- | --- |
| R0 渲染 | 图像采样、脏区更新与提交、完整边界与确定性像素验证 |
| R1 字体 | 完整系统字体发现；hinting；CFF/CFF2、彩色字形等字体格式。当前自动回退仍依赖有限常见路径 |
| R2 排版 | 印度系、缅甸文、高棉文、藏文、Hangul Jamo 等脚本专门处理；完整规范化、可变字体、竖排、完整语言/特性选择 |
| P0 平台 | 原生 Wayland、完整键盘布局支持；Linux 当前使用 X11/XWayland |
| P8 分发 | 完整综合示例与应用场景、干净发行目录和正式发行验收 |

P7 当前覆盖普通控件与纯文本。UIA/AT-SPI 的文档、富文本、注释和表格单元格专用扩展接口
未实现，不应由已有 Invoke/Value/Range/Selection/Text 通路推断这些扩展也已支持。

## 仍需真实桌面验收

- Windows 与 Linux 中文输入法：预编辑、提交、候选位置、取消及跨控件焦点切换。
- Narrator/NVDA/Orca 的实际读屏体验；协议客户端通过只证明所测接口可遍历和操作。
- Linux 的真实桌面 Portal backend 文件选择流程；独立 D-Bus 对端覆盖成功、取消、错误和 URI 解码。
- 多 DPI、缩放、嵌套布局/滚动、隐藏页、焦点和多窗口模态组合。
- 完整数据应用与最终双平台安装体验。

## CI 与收尾

GitHub Actions 的双平台构建、定向 GUI 检查和解包自检用于防止已交付能力回退。
结果以对应提交的 [Actions 运行](https://github.com/ChaceQC/txc/actions) 为准，不能用本地记录代替。
分支推送生成开发包 artifact；正式 Release 仅在版本 tag 推送且两端检查通过后发布。

本地 `build/` 清理此前被自动审批以 `blocked by policy` 拒绝，因此保留；
历史记录中的额外 Linux 打包文件也未作为本轮改动删除。源码提交和 CI 成功不自动表示
开发机目录已经整理为干净的正式发行目录。
