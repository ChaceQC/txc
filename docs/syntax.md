# .tx 语法与类型规则

`try { } exception type as e { }` 的类型匹配、作用域和传播规则见[解析与可恢复错误](errors_and_parse.md)。可捕获类型由 `error.txh` 定义：`parse_error`、`io_error`、`process_error`、`database_error`、`security_error`、`cancelled_error` 和兜底的 `runtime_error`；具体类别必须写在兜底分支之前。`try`、`exception` 为保留关键字。示例见 [parse_errors.tx](../examples/parse_errors.tx)。

从 `dict`、`array` 等动态容器取出的 `any` 值可显式写 `value as bool`；仅当实际值就是 `bool` 时成功，不对数值或字符串执行 Python 式真值转换。该规则用于接收类型明确的命名参数等动态边界，失败仍为可捕获的运行时类型错误。

内置参数化类型 `vector<T>` 可递归使用具体的复合元素类型，元素仍须在编译期有完整类型；`void`、`none`、动态 `any` 和未定签名的 `fn` 不能作元素。共享、显式动态恢复和遍历规则见 [类型化 vector](typed_vectors.md)，示例见 [typed_vectors.tx](../examples/typed_vectors.tx)。

`option<T>`、`result<T>`、`result<void>` 的构造、状态检查、错误传播和旧结果转换见[option 与 result](option_result.md)。它们是内置参数化类型；方法调用在编译期根据完整的 T 选定，不引入用户泛型语法或新的 `match` 关键字。

内置 `bytes` 表示不可变原始字节，支持 `vector<bytes>`，并可作为 `array`、`dict` 的值；显式编码及文件流接口见[字节值、编码与文件流](bytes_file_stream.md)。

不透明内置类型 `secret_bytes` 由 `secret.txh` 的 `from_bytes` 或 `random` 创建。普通赋值和参数传递共享同一受控缓冲；`secret.close` 清零缓冲并使全部别名失效，最后一个别名释放时也清零。它不能默认打印、装入 `any`、序列化、`deep_copy`，也不能作为结构体、类或容器字段；只能显式调用 `secret.to_bytes` 复制导出。导入时源 `bytes` 和导出后的 `bytes` 都不受秘密缓冲清零保证。接口及平台限制见[秘密字节](secret_bytes.md)，用法见[示例](../examples/secret_bytes.tx)。

`password.txh` 接收 `secret_bytes`，输出 PHC 格式的 Argon2id 哈希字符串。密码验证、参数升级与资源限制见[Argon2id 密码存储](password.md)。

不透明内置类型 `cancel_source` 与 `cancel_token` 分别表示取消权与只读观察权，只能由 `cancel.txh` 的函数创建或取得。令牌与单调截止时间、阻塞等待及跨模块传递规则见[取消令牌与截止时间](cancellation.md)。

不透明内置类型 `fs_watcher` 只能由 `fs.watch` 创建。普通赋值共享同一监视状态，`fs.close_watch` 使所有别名失效，`deep_copy` 不复制监视器；监视器当前不满足 `Send/Sync`。接口与资源清理规则见[文件系统与路径扩展](filesystem_path.md#71-文件系统元信息筛选与监视)，用法见[定向示例](../tests/stdlib/filesystem_path_extended.tx)。

不透明内置类型 `process_child` 与 `process_pipe` 只能由 `process.txh` 取得，普通赋值及从 `any` 显式恢复共享同一状态；禁止手工构造、`deep_copy` 和未经证明的跨线程传递。进程关闭使父侧管道别名失效，等待成功缓存退出状态且仍可读完输出。接口与失败语义见[子进程与管道](process.md)，用法见[process.tx](../examples/process.tx)。

不透明内置类型 `db_connection/db_statement/db_cursor/db_transaction` 由 `db.txh` 创建，赋值及从 `any` 恢复共享资源状态；禁止手工构造、`deep_copy` 和跨线程传递。`db_pool` 支持 `Send/Sync` 与共享赋值，但禁止手工构造和 `deep_copy`；池中借出的连接仍只允许借用线程访问，归还使旧借用及其子资源失效。`db_row/db_value` 是不可变行快照与标记 SQL 值，支持复制但当前同样不声明 `Send/Sync`。SQL NULL 由 `option<T>` 的无值表示，游标无行由 `option<db_row>` 的无值表示，列缺失与类型错误分别抛数据库错误。参数从 1、列从 0 开始；关闭连接使所有子资源别名失效，但已读取行仍可使用。标准库参数绑定 `db.bind` 必须经模块别名限定调用，未限定的 `bind(...)` 继续表示闭包构造；该标准库声明不解除用户函数的保留名限制。完整接口、事务和驱动差异见[数据库](db.md)，用法见 [sqlite.tx](../examples/sqlite.tx) 和 [postgres.tx](../examples/postgres.tx)。

不透明内置类型 `json_reader` 与 `json_writer` 只能由 `json.txh` 创建，用于逐项读取或生成根数组。赋值及从 `any` 显式恢复共享同一游标；禁止手工构造、`deep_copy` 和跨线程传递。`close` 只释放游标持有的文件流引用，不关闭调用方的流；写入必须显式 `finish` 才补齐根数组。接口、限额与失败后的状态见 [JSON 增量接口](json.md#增量读写与-schema)，示例见 [json_stream.tx](../examples/json_stream.tx)。

不透明内置类型 `csv_reader` 与 `csv_writer` 使用相同的共享游标、`any` 恢复、禁止复制和跨线程传递规则。`csv.next_row` 返回 `option<vector<str>>`；表头快照与已返回行独立于游标，关闭后仍可使用。dialect、字段限额与失败语义见 [CSV](csv.md)，示例见 [csv_stream.tx](../examples/csv_stream.tx)。

`assert_send(value)` 与 `assert_sync(value)` 在编译期检查跨线程传递/共享规则，并在运行时正常求值该实参。`move(value)` 消费唯一拥有的可变 Send 局部变量；原变量随即不可读写。普通赋值别名、容器/字段/闭包捕获或未知调用可能保留别名时，`move` 会在源码位置报错；条件、循环和异常分支中暂不允许移动。可变复合闭包捕获须写成 `bind(work, move(value))`。完整类型范围、线程边界和锁卫士生命周期见[Send/Sync 规则](send_sync.md)。`join_handle<T>`、`mutex<T>`、`rw_lock<T>`、锁卫士、`atomic<T>`、`channel<T>` 与只读 `selected<T>` 是新增的内置参数化类型；目前 T 仅限文档列出的标量。`selected<T>` 有 `index: int` 和 `value: option<T>` 两个只读字段。

`async def`、`await` 和 `task<T>` 的静态类型、作用域及取消规则见[结构化任务与异步函数](task.md)。

`map<K, V>`、`set<T>`、`ordered_map<K, V>`、`ordered_set<T>`、`heap<T>`、`queue<T>`、`deque<T>` 的类型参数、接口、共享和快照遍历规则见[类型化容器](typed_containers.md)。这些类型在变量、函数及 `.txh` 签名、struct/class 字段中保留完整静态类型。`entry<K, V>` 是映射条目快照的内置只读值类型，字段为 `key: K` 和 `value: V`，不能自行构造或修改字段。`deque<T>` 与 `vector<T>` 使用相同的具体元素类型规则，支持整数下标读写；两端增删为 O(1)，中间插入/删除为 O(n)。普通函数的静态函数类型及作为参数传递的规则见[函数值与函数参数](function_values.md)。

`priority_entry<T>` 是只读优先级条目；`heap/queue` 已支持复合元素和批量构建。比较器签名、稳定次序和失败语义见[类型化容器](typed_containers.md#heap-和-queue)。

`algorithm.txh` 中允许受限的 `def name<T, U>(...) -> ...` 外部接口声明。类型变量由调用处的 `vector<T>`、具体值与完整 `fn` 签名确定，编译器在源码位置检查签名并选定 ABI；目前不允许用户泛型函数体。具体签名见[容器算法](algorithm.md#44-与-45-的接口契约)。

本文描述当前编译器已经实现的语言范围。源码使用 UTF-8；标识符目前只接受 ASCII 字母、数字和下划线，首字符不能是数字，大小写敏感。支持 # 和 // 单行注释。类、接口、抽象方法、多继承及运行时转换见 [class 说明](classes.md)。

顶层可写 import "路径.tx" 导入其他模块；路径、重复导入和命名规则见 [模块说明](modules.md)。

## 基本格式

- 代码块使用 { 和 }，缩进只用于排版。
- 语句以换行结束，也可以紧接所在代码块的右大括号；当前不使用分号。
- def（包括类方法）、struct、class、abstract class、interface、if、else、while、for 的左大括号可以与头部写在同一行，也可以在头部结束后另起一行；中间可以有空行或注释行。
- else 和 else if 可以紧接前一个右大括号，也可以另起一行；推荐另起一行。else 与后续 if 之间也允许空行或注释行。
- 圆括号和数组方括号内可以换行；结构头部与左大括号之间也可以换行。其余位置的换行会结束当前语句。

函数、参数和返回值的格式如下：

```tx
def add(left: int, right: int) -> int
{
    return left + right
}
```

返回值类型可写成 `-> int` 等具体类型；无返回值函数既可写 `-> void`，也可省略箭头和返回类型。非 `void` 函数必须在所有执行路径返回对应类型的值；`void` 函数可以自然结束，也可以使用不带表达式的 `return` 提前结束。带值的 `return` 不能用于 `void` 函数，不带值的 `return` 不能用于非 `void` 函数。程序入口仍必须是无参数、返回 int 的 `def main() -> int`。

程序参数通过导入 `system.txh` 后调用 `args() -> vector<str>` 获取，不包含可执行文件名；运行时在调用 main 前完成 UTF-8 参数初始化，详见[系统与环境变量](system_env.md)。

`none` 是表示值暂未初始化的字面量，不作为新接口的一般数据类型。编译器内部仍用专门标记区分它与 `int`、`float` 等值；旧接口中的 `none` 形参或返回标注暂保留兼容性，例如字典标准库的 none 键重载。新代码需要可缺省参数时写 `a: int = none` 等具体类型标注。

```tx
def greet(name: str) {
    print("你好，" + name)
}

def stop_early(done: bool) -> void {
    if done
    {
        return
    }
    else
    {
        print("继续")
    }
}
```

函数支持调用自身，也支持同一模块内的函数相互调用；被调用函数可以写在调用者后面。递归需要由程序自行设置终止条件。模块之间的循环导入仍然不允许，递归结构体也尚未支持。直接递归、相互递归和无返回值函数递归见 [递归示例](../examples/recursion.tx)。

### 函数参数默认值

普通形参可在类型后写 `= 表达式`，例如 `def fetch(url: str, timeout: float = none, params: dict = none) -> str`。有默认值的普通形参必须排在必需形参之后、`*args` 和 `**kwargs` 之前；可变参数和运算符参数不能声明默认值。调用方可省略尾部位置实参，也可用命名实参跳过任意有默认值的形参。默认表达式的静态类型必须与形参类型一致；`T = none` 对非 `void`、非函数的具体类型 `T` 都允许。默认表达式不能引用本函数的形参、`self`、`super` 或局部变量。

调用时先按源码顺序求值显式实参和展开表达式，再按形参声明顺序仅求值缺失的默认表达式。默认表达式在每次调用时重新求值；`{}`、`[]` 和 `map<str, str>()` 因而各次产生独立容器。`T = none` 的调用方可传 `T` 或 `none`；函数体内该参数按 `any` 读取，须用 `is_none(value)` 判断，再用 `as T` 或明确的 `T` 变量恢复具体类型。该值通过带类型标记的运行时句柄传递，不把空值转成 0、0.0、false 或空容器。默认表达式出错时沿用普通调用的可恢复错误路径。带 `*`/`**` 展开的调用在展开后确定缺失形参，再补默认值；显式 `none` 不视为缺失。若多个重载都能通过默认值匹配且无法唯一选定，编译时报歧义。

含 `T = none` 形参的普通函数仍可作为 `fn` 函数值传递，间接调用入口会把具体 `T` 值装入带标记的参数句柄。`fn` 类型记录完整形参类型，不保存默认表达式，因此通过函数值调用时仍需提供所有实参。

`bind(function, prefix_arg, ...)` 将已知签名函数的前若干参数按值捕获，返回剩余参数签名的闭包。例如 `def add(base: int, value: int) -> int` 可用 `fn(int)->int plus_five = bind(add, 5)` 创建闭包。普通捕获按赋值语义保存：标量复制，可变复合对象持有共享引用；需要独立对象时显式 `deep_copy` 后捕获。跨线程闭包另外检查每个捕获：可变 Send 对象须唯一移动，例如 `thread.spawn(bind(work, move(values)))`；字符串、字节和受控同步句柄按其类型规则传递。闭包拥有捕获值，可跨创建它的作用域存活；调用期间对内部值的借用只在该次同步调用内有效，不能把借用地址作为 TX 值保存。闭包失败沿原函数的错误类别传播。显式 `&` 引用捕获暂不提供，避免产生逃逸的栈引用。

函数可在普通参数后声明 `*args` 和 `**kwargs`，各至多一个，顺序必须如此。`*args` 的类型为 `array`，`**kwargs` 的类型为 `dict`；可省略这两个参数的类型标注，也可分别写 `: array`、`: dict`。普通参数仍需显式标注类型，当前没有默认值。多余的位置实参进入 `args`，未对应普通参数名的命名实参进入 `kwargs`。调用时可写 `name=表达式`、`*数组表达式` 和 `**字典表达式`；位置实参（包括 `*`）应写在命名实参（包括 `**`）之前。实参从左到右求值；重复命名、同一参数同时接受位置和命名值、缺少必需参数，以及多余实参没有对应收集参数，都会报错。`**` 展开时字典的键必须是 `str`。显式实参按静态类型匹配；展开所得的值在运行时检查目标参数类型。对于带展开的重载调用，必须能在编译期唯一确定重载。

```tx
def show(first: int, *args, **kwargs) {
    print(first)
    print(len(args))
    print(kwargs["label"])
}

def main() -> int {
    array more = [2, 3]
    dict options = {"label": "完成"}
    show(1, *more, **options)
    return 0
}
```

同一模块内可以定义多个同名函数，只要它们的参数类型列表不同；参数名和返回类型不参与重载区分。调用时按实参的静态类型精确匹配，不能靠返回值类型选择重载，也不会为匹配重载而隐式转换 `int` 与 `float`。需要指定类型时可使用 `as` 显式转换。`main`、内置函数和结构体构造不参与函数重载。示例见 [函数重载示例](../examples/overload.tx)。

### 哈希键与有序比较契约

`map<K,V>` 和 `set<K>` 的内置键 `int`、`float`、`bool`、`str` 继续使用原有相等与哈希规则。用户结构体作为键时，必须声明 `def operator ==(other: K) -> bool` 和 `def hash_key() -> int`；`self` 是隐含接收者，两者都不能声明默认参数。结构体的字段只允许 `int`、`float`、`bool`、`str`、`bytes` 或同样满足本规则的结构体，不能包含可变容器、类或资源句柄。编译器在键类型使用处检查这些签名和字段；不满足时以该源码位置报中文错误。键存入容器时复制键值，之后修改原结构体不会改变已存键。`keys()` 返回独立键值；修改返回的键也不会改变容器中的键。

`hash_key()` 必须对相等键返回同一整数；编译器能验证签名，无法证明函数体是否遵守此数学约束。哈希和相等方法不应读取可变的外部状态或修改接收者。浮点 NaN 不能作哈希键；`+0.0` 与 `-0.0` 相等，内置哈希必须给出相同结果。若用户结构体包含浮点字段，其方法也必须遵守同样规则。

有序键的默认顺序支持 `int`、`float`、`bool`、`str`，或带 `def operator <(other: K) -> bool` 的结构体；也可在有序容器构造时显式传入 `fn(K,K)->int` 比较器。比较器以负、零、正表示小于、相等、大于，必须形成严格弱序；比较器状态在有序容器存活期间不能改变排序关系。浮点 NaN 不可作有序键，正负零等价。现有无序 `map/set` 的迭代顺序不变。

### 类型化迭代器

`iterator<T>` 是内置参数化类型；`vector<T>.snapshot_iter()` 和 `vector<T>.live_iter()` 创建对应迭代器，`next() -> option<T>` 逐项取值，`close()` 显式使迭代器及其所有普通赋值别名失效。`next()` 首次返回无值后，迭代器永久到达终点；`close()` 后调用 `next()` 报 `runtime_error/invalid_state`。普通赋值共享游标，`deep_copy` 得到独立游标与独立容器快照。

快照迭代器创建时固定向量的元素顺序和数量；复合元素的内部可变对象仍遵循普通共享引用规则。实时迭代器持有原向量的共享引用，每次按当前下标读取当前值；中途插入或删除导致的下标移动可以让元素被跳过或再次读到，追加的元素只在尚未到达终点时可见。重新绑定原变量不改变迭代器持有的向量。已有 `for value in vector` 继续按进入循环时的长度逐次读取当前下标，不改为上述任一种迭代器。用户回调或循环体在一次 `next()` 之后报错时，游标已前进，该错误按普通调用路径传播；若被捕获，可继续从下一位置读取。

## 语句

下表中的“表达式”遵循后文的运算符规则。

| 写法 | 含义 |
| --- | --- |
| int count = 0 | 显式声明 int 变量 |
| bool ready = true | 显式声明 bool 变量 |
| float rate = 1.5 | 显式声明 64 位浮点变量 |
| str message = "你好" | 显式声明 UTF-8 字符串变量 |
| array values = [1, 2.5, "三"] | 只给初始值，长度由元素数决定 |
| array[5] values | 只给长度，5 个位置填充 none |
| array[5] values = [1, 2.5] | 给长度和部分初值，剩余位置填充 none |
| auto count = 0 | 编译时由初值推断类型 |
| count = count + 1 | 对已有变量赋值 |
| count += 1 | 对 int、float 或 str 左侧执行加法赋值；str 执行拼接 |
| count -= 1 | 对 int 或 float 左侧执行减法赋值 |
| count++ | 对 int 或 float 目标加 1，并返回更新后的值 |
| count-- | 对 int 或 float 目标减 1，并返回更新后的值 |
| left, right = values | 将数组的两个元素分别绑定或赋给变量 |
| if 条件 { ... } | 条件分支；可接多个 else if 条件 { ... }，最后可接 else { ... } |
| while 条件 { ... } | 条件循环 |
| for i in 起点..=终点 { ... } | 含终点的整数区间循环 |
| for value in values { ... } | 遍历数组元素或字典键，循环变量只读 |
| values[0] = 9 | 修改数组元素，索引从 0 开始 |
| user.age = 20 | 修改结构体字段 |
| return 表达式 | 从函数返回 |
| print(值, ...) | 输出零个或多个值，默认以空格分隔并换行 |

函数调用也可以单独作为一条语句。`=`、`+=`、`-=` 的左侧以及 `++`、`--` 的目标可以是已有变量、其数组或字典元素、结构体字段；目标必须可赋值。赋值时，先从左到右各求值一次目标中的索引，再求值右侧，最后在当前容器中定位元素并写入。数组和字典元素的静态类型是 `any`，目前不支持对它们使用 `+=`、`-=`、`++` 或 `--`。`++` 和 `--` 只接受后置写法，可以作为独立语句或参与表达式；它们先修改目标，再返回修改后的值，对 `float` 目标增减 `1.0`。`+=`、`-=` 的右侧类型必须与目标相同；`int` 的算术溢出沿用运行时错误。auto 必须有初值。区间 for 的两个边界必须是 int，且各求值一次；起点大于终点时循环零次。两种 for 的循环变量都只在循环体内可读。遍历数组或字典时，循环变量的静态类型为 any。

`a, b = values` 只允许互不相同的简单变量名。右侧必须为数组，且在运行时要求长度恰好等于左侧变量数；右侧只求值一次。已有变量按原类型赋值，新变量在当前作用域声明为 `any`。所有元素先取出并检查，再依次写入变量。

### 条件分支

`if` 后可接零个或多个 `else if`，末尾的 `else` 可省略。每个条件的静态类型必须是 `bool`，每个分支体都必须用花括号包围。条件从上到下求值，只执行第一个条件为 `true` 的分支，后续条件和分支不再执行；全部为 `false` 时执行末尾的 `else`，没有 `else` 则直接继续后面的语句。

```tx
if score >= 90
{
    print("优秀")
}
else if score >= 60
{
    print("及格")
}
else
{
    print("未及格")
}
```

各分支拥有独立的局部作用域，前一分支声明的变量在后续条件和分支中不可见。`else if` 等价于在 `else` 块中嵌套一个 `if`，沿用已有的类型检查和所有路径返回检查。可运行示例见 [else if 示例](../examples/else_if.tx)。

## 表达式

目前支持十进制整数、浮点数、双引号字符串、true/false、数组和字典字面量、变量、函数调用、索引、字段访问、圆括号和以下运算符。赋值与 ..= 不是普通表达式运算符。

| 优先级（高到低） | 运算符 | 类型要求与结果 |
| --- | --- | --- |
| 1 | 调用 ()、索引 []、字段 .、as 类型、后置 ++、-- | 访问值、显式转换或先更新目标并返回新值；++、-- 的目标必须是可赋值的 int 或 float |
| 2 | 一元 -、! | - 接收 int 或 float；! 接收 bool |
| 3 | *、/、% | `*`、`/` 两侧为相同数值类型，结果类型不变；`%` 两侧必须是 int，结果为 int |
| 4 | +、- | 两侧为相同数值类型；str + str 可拼接 |
| 5 | <、<=、>、>= | 两侧为相同数值类型，结果 bool |
| 6 | ==、!= | 两侧类型相同，结果 bool |
| 7 | & | 两侧 int，结果 int |
| 8 | ^ | 两侧 int，结果 int |
| 9 | \| | 两侧 int，结果 int |
| 10 | && | 两侧 bool，结果 bool |
| 11 | \|\| | 两侧 bool，结果 bool |

同一优先级的二元运算从左到右结合。函数实参和普通二元表达式从左到右求值；`&`、`^`、`|` 对有符号 64 位 `int` 的位模式运算，两侧都求值；`&&` 与 `||` 短路求值。整数除法向零截断；整数 `%` 返回对应的余数，结果与左操作数同号或为零，例如 `-7 % 3` 为 `-1`、`7 % -3` 为 `1`。`-9223372036854775808 % -1` 为 `0`，取余时除数为零会在运行时报错。可运行用法见 [整数取余示例](../examples/modulo.tx)。位运算示例见 [位运算符示例](../examples/bitwise_operators.tx)，复合赋值和后置更新的可运行用法见 [更新运算符示例](../examples/update_operators.tx)。

### 自定义运算符

`struct` 和 `class` 可在类型体内用 `def operator 运算符(...) -> 类型` 声明实例运算符。`self` 是隐含的左操作数：一元 `-`、`!` 不写参数，二元 `+`、`-`、`*`、`/`、`&`、`^`、`|`、`==`、`!=`、`<`、`<=`、`>`、`>=` 恰好写一个显式类型参数。`!`、比较与相等运算符必须返回 `bool`，其他运算符必须有非 `void` 返回类型。不能使用可变参数。`struct` 中只允许这种成员方法；`class` 的运算符遵守普通方法的访问控制、继承及 `virtual`、`override` 规则。

`a 运算符 b` 只在 `a` 的静态类型及其类祖先中查找成员运算符，按参数类型选择唯一重载；不会交换左右操作数或进行隐式数值转换。虚运算符在选定重载后按实际类分派。`any` 不按运行时类型寻找运算符；需要先显式转换。`+=` 和 `-=` 使用相应的 `+`、`-` 结果赋回左值，结果必须可赋给左值类型，左值位置与右侧都只求值一次。运算符方法不会隐式复制或修改对象，是否创建新对象由方法体决定。`&&`、`||`、赋值、索引、调用、后置 `++`、`--` 暂不支持自定义重载。

单文件用法见 [运算符重载示例](../examples/operator_overloads.tx)。通过 `.txh` 导出时，声明与实现按[模块文件分工](modules.md)放置。

## 强类型规则

`int` 和 `float` 的数值范围如下：

| 类型 | 范围与精度 |
| --- | --- |
| `int` | 有符号 64 位整数，精确范围为 -9223372036854775808 到 9223372036854775807（含端点） |
| `float` | IEEE 754 双精度（binary64）；最大有限正值约为 1.7976931348623157e308，最小正正规值约为 2.2250738585072014e-308，最小正非正规值约为 4.9406564584124654e-324；负值范围对称，另有正零和负零；有效精度为 53 位二进制，通常约 15～17 位十进制数字 |

浮点数不是上述区间内的每个实数都能精确表示。浮点字面量和 `str as float` 必须能解析为有限的双精度值，超出范围会报错；浮点运算仍按 IEEE 754 进行，结果可能出现无穷大或 NaN。`str` 保存 UTF-8 文本，`bool` 只有 true 和 false。静态类型已知的不同基本类型之间没有隐式转换，if 和 while 的条件必须是 bool。
- 当右侧静态类型为 `any`、目标明确为 `int`、`float`、`str`、`array` 或 `dict` 时，显式类型的变量声明、普通 `=` 赋值和函数返回会在运行时转换或检查实际值。前三种目标沿用对应的 `as` 转换；`array` 和 `dict` 只接受实际类型完全相同的容器，成功后保留共享引用，类型不符时报可捕获的运行错误。数组和字典元素读取的静态类型都是 `any`，因此可以写 `dict child = object["child"]`、`array items = object["items"]`，继续用普通索引读写。`auto` 不推断元素的实际类型，仍得到 `any`。函数实参、重载选择、运算符、复合赋值及条件表达式不使用此规则。
- `any` 可用于显式类型声明与函数签名；普通 `any` 形参仍须接收静态类型为 `any` 的表达式。标为 `any = none` 的可空形参允许调用点传具体非 `void` 值，并在调用点装箱；函数体仍按 `any` 检查。
- array 和 dict 可混放 int、float、str、bool、结构体、数组、字典和 none。读取元素得到 any；print 可直接输出其中的所有受支持值。若元素实际是结构体，可直接访问字段；若实际是数组或字典，可直接传给 len。这些操作会在运行时检查元素类型。
- 普通函数参数必须显式写类型；`*args` 和 `**kwargs` 的类型标注可省略。有返回值函数必须写返回类型，无返回值函数可以写 `-> void` 或省略返回类型。局部 auto 在编译时推断出固定类型，后续赋值仍须匹配该类型。
- 变量只在声明所在的代码块内可见；同一作用域不能重复声明，内层代码块可以遮蔽外层变量。
- 内置 `print()` 输出一个空行；`print(值, ...)` 按顺序输出零个或多个值，默认以空格分隔并在末尾换行。可在值后使用 `sep=str` 和 `end=str` 命名参数覆盖分隔符与结尾，不能重复，也不接受其他命名参数或 `*`、`**` 展开。每个值可以是 int、float、str、bool、none、array、dict、结构体或 any 中的这些值；静态类型已知时在编译期检查。`print` 没有返回值，不能用于初始化变量或作为函数返回值。普通 `void` 函数调用也遵守此规则。
- 整数字面量按十进制读取。非负字面量只能在 0 到 9223372036854775807 之间；一元 `-` 后可直接写 `9223372036854775808`，构成最小 `int` 值 `-9223372036854775808`。单独的 `9223372036854775808` 或更大的整数常量会报编译错误。整数算术溢出和除零在运行时报错。边界用法见 [数值边界示例](../examples/numeric_bounds.tx)。

## 字符串、数组、字典与结构体

- 字符串用双引号包围，支持 \\, \", \n、\r、\t 转义；可以用 + 拼接、用 == 和 != 比较。当前不提供按 Unicode 字符直接索引；`len(str)`、`string.find/slice` 使用 Unicode 标量位置，字素边界、显式 locale 比较和正则匹配的字节/标量位置见 [Unicode 与正则模块](unicode_regex_encoding.md)。
- 浮点字面量可写为 1.5、1e3、1.5e-2。静态类型为 `int`、`float` 或 `str` 的值不会自动跨类型转换；2 as float 得到 2.0，3.75 as int 得到 3。静态类型为 `any` 的值可按上面的目标类型规则转换。as 也支持字符串与数值的显式转换，以及 class/interface 引用的运行时类型转换；详细规则分别见 [标准库说明](standard_library.md)和 [class 说明](classes.md)。to_float(整数) 仍可使用。float 除以零会在运行时报错。
- 数组类型写为 array，同一数组内元素可以有不同类型。三种声明形式为 array[长度] 名称、array[长度] 名称 = [初值...] 和 array 名称 = [初值...]；前两种的长度可以是 int 表达式，运行时结果必须非负。初值数不能超过指定长度，未提供初值的位置填充 none。[] 是长度为 0 的数组。
- 数组索引从 0 开始，索引必须是 int，越界会在运行时报错。len(数组) 返回 int；数组元素实际存放数组时，也可以直接写 len(外层数组[索引])。is_none(数组元素) 可判断空位置。数组元素可用 = 赋任意受支持的值。for 遍历数组时读取一次数组表达式并记录当时的长度；遍历期间仍读取共享数组中的当前元素，新追加的元素不进入本次遍历。
- 字典类型写为 `dict`，字面量写为 `{键: 值, ...}`，空字典写为 `{}`，也可用 `dict 名称 = 初值` 声明。键必须是可哈希的 `int`、`float`、`bool`、`str` 或 `none`；值可为任意受支持的值类型。键按类型和值比较，重复键保留最后赋入的值；字典不保证遍历顺序。`字典[键]` 读取元素，键不存在时在运行时报错；`字典[键] = 值` 可以插入或更新。`len(字典)` 返回键数；`for key in 字典` 遍历进入循环时的键快照，循环变量类型为 any。允许缺键的查询、删除等操作见[字典标准库](standard_library.md#字典操作)。
- 顶层用 struct 定义字段及运算符成员。字段按声明顺序构造，字段名必须唯一且类型有效。结构体可以作为函数参数、返回值和数组元素；字段可以是 array 或先前声明的结构体。当前不支持递归结构体。
- 可序列化数据结构在结构体名称后写 `serde(version=正整数, unknown="reject"|"ignore"|"preserve", reserved=[已删除字段编号...])`。每个普通字段末尾写 `serde(正整数字段编号)`；有默认值的字段可写 `serde(编号, default=字面量)`；`option<T>` 字段缺失时取 `none`。`unknown="preserve"` 时须有且仅有一个 `dict` 字段写 `serde(unknown)` 接收未知字段。字段编号不能重复或占用 `reserved`，0 留给 CBOR schema 版本；JSON 的 `$schema` 也为保留字段。默认值目前只接受与字段类型相同的 `int/float/bool/str` 字面量。仅允许 `int/float/bool/str/bytes`、这些类型及已标记结构体的 `vector<T>`/`option<T>` 和已标记的嵌套结构体；函数、类、动态 `any/array/dict`（未知字段容器除外）及资源句柄不能成为可序列化字段。详见 [serde 模块](serde.md)。
- `serde.deserialize_json<类型>(文本)` 与 `serde.deserialize_cbor<类型>(字节)` 使用显式返回类型参数，类型须为已标记的结构体。这是当前仅支持的调用位置类型实参语法；普通泛型函数仍由值参数推断类型。解码器只接受声明的 schema 版本；跨版本转换须显式读取旧结构体，再由用户函数构造新结构体。
- `struct`、`class` 在 `.txh` 和配对 `.tx` 中的放置规则不同，见 [模块导入：文件分工](modules.md)。
- 数组、字典、结构体和类对象默认按引用共享：赋值、传参、返回和放入其他复合值时只复制引用，之后通过任一引用修改字段或元素，其他引用都能看到。`deep_copy(值)` 显式递归复制可达的数组、字典、结构体和类对象，返回值保持实参的静态类型；`any` 也可传入，结果保留其实际类型。复制会保留原对象图中的共享关系和循环关系，但新对象图与原图互不共享这些复合对象。类对象复制字段与运行时类型，不重新执行 `init`；新对象释放时仍按通常规则调用 `deinit`。不可变的数字、布尔值、字符串和 none 按值处理。不可达的引用环由[循环回收器](garbage_collection.md)在安全点处理，`deep_copy` 也会保留环。
- `int`、`float` 和 `bool` 的赋值直接复制值。例如 `int a = 2`、`auto b = a`、`b = 3` 执行后，`a` 仍为 `2`，`b` 为 `3`。
- `==` 和 `!=` 目前用于相同类型的 int、float、str、bool、none；复合类型暂不直接比较。print 可输出数组、字典和结构体，嵌套字符串会加引号并转义；字典输出顺序不保证，结构体保持字段声明顺序。数组元素里结构体的字段可直接读取，当前不支持直接修改该动态字段。

```tx
struct person {
    name: str
    scores: array
}

def main() -> int {
    auto user = person("Ada", [8.5, 9.0])
    user.scores[1] = 9.5
    print(user.name)
    print(user.scores[1])
    print(len(user.scores))
    return 0
}
```

更多可运行的用法见 [数据类型示例](../examples/data_types.tx)。`struct` 只支持运算符成员；`class` 的普通方法见 [class 说明](classes.md)。

## 完整示例

```tx
def sum_to(n: int) -> int {
    auto total = 0

    for i in 1..=n {
        total += i
    }

    return total
}

def main() -> int {
    print(sum_to(10))
    return 0
}
```
