# .tx 语法与类型规则

本文描述当前编译器已经实现的语言范围。源码使用 UTF-8；标识符目前只接受 ASCII 字母、数字和下划线，首字符不能是数字，大小写敏感。支持 # 和 // 单行注释。

顶层可写 import "路径.tx" 导入其他模块；路径、重复导入和命名规则见 [模块说明](modules.md)。

## 基本格式

- 代码块使用 { 和 }，缩进只用于排版。
- 语句以换行结束，也可以紧接所在代码块的右大括号；当前不使用分号。
- def、struct、if、else、while、for 的左大括号必须与该结构的头部写在同一行。else 可以紧接前一个右大括号，也可以写在下一行。
- 圆括号和数组方括号内可以换行；其余位置的换行会结束当前语句。

函数、参数和返回值的格式如下：

```tx
def add(left: int, right: int) -> int {
    return left + right
}
```

返回值类型可写成 `-> int` 等具体类型；无返回值函数既可写 `-> void`，也可省略箭头和返回类型。非 `void` 函数必须在所有执行路径返回对应类型的值；`void` 函数可以自然结束，也可以使用不带表达式的 `return` 提前结束。带值的 `return` 不能用于 `void` 函数，不带值的 `return` 不能用于非 `void` 函数。程序入口仍必须是无参数、返回 int 的 `def main() -> int`。

```tx
def greet(name: str) {
    print("你好，" + name)
}

def stop_early(done: bool) -> void {
    if done {
        return
    }
    print("继续")
}
```

函数支持调用自身，也支持同一模块内的函数相互调用；被调用函数可以写在调用者后面。递归需要由程序自行设置终止条件。模块之间的循环导入仍然不允许，递归结构体也尚未支持。直接递归、相互递归和无返回值函数递归见 [递归示例](../examples/recursion.tx)。

同一模块内可以定义多个同名函数，只要它们的参数类型列表不同；参数名和返回类型不参与重载区分。调用时按实参的静态类型精确匹配，不能靠返回值类型选择重载，也不会为匹配重载而隐式转换 `int` 与 `float`。需要指定类型时可使用 `as` 显式转换。`main`、内置函数和结构体构造不参与函数重载。示例见 [函数重载示例](../examples/overload.tx)。

## 语句

下表中的“表达式”遵循后文的运算符规则。

| 写法 | 含义 |
| --- | --- |
| int count = 0 | 显式声明 int 变量 |
| bool ready = true | 显式声明 bool 变量 |
| float rate = 1.5 | 显式声明 64 位浮点变量 |
| str message = "你好" | 显式声明 UTF-8 字符串变量 |
| array values = [1, 2.5, "三"] | 只给初始值，长度由元素数决定 |
| array[5] values | 只给长度，5 个位置填充 none |
| array[5] values = [1, 2.5] | 给长度和部分初值，剩余位置填充 none |
| auto count = 0 | 编译时由初值推断类型 |
| count = count + 1 | 对已有变量赋值 |
| count += 1 | int 变量的加法赋值 |
| if 条件 { ... } else { ... } | 条件分支，else 可省略 |
| while 条件 { ... } | 条件循环 |
| for i in 起点..=终点 { ... } | 含终点的整数区间循环 |
| for value in values { ... } | 遍历数组元素，循环变量只读 |
| values[0] = 9 | 修改数组元素，索引从 0 开始 |
| user.age = 20 | 修改结构体字段 |
| return 表达式 | 从函数返回 |
| print(表达式) | 输出一个可打印值，并换行 |

函数调用也可以单独作为一条语句。赋值左侧可以是已有变量、其数组元素或结构体字段；auto 必须有初值。区间 for 的两个边界必须是 int，且各求值一次；起点大于终点时循环零次。两种 for 的循环变量都只在循环体内可读。遍历数组时，循环变量的静态类型为 any。

## 表达式

目前支持十进制整数、浮点数、双引号字符串、true/false、数组字面量、变量、函数调用、索引、字段访问、圆括号和以下运算符。赋值与 ..= 不是普通表达式运算符。

| 优先级（高到低） | 运算符 | 类型要求与结果 |
| --- | --- | --- |
| 1 | 调用 ()、索引 []、字段 .、as 类型 | 访问值或显式转换数值类型 |
| 2 | 一元 -、! | - 接收 int 或 float；! 接收 bool |
| 3 | *、/ | 两侧为相同数值类型，结果类型不变 |
| 4 | +、- | 两侧为相同数值类型；str + str 可拼接 |
| 5 | <、<=、>、>= | 两侧为相同数值类型，结果 bool |
| 6 | ==、!= | 两侧类型相同，结果 bool |
| 7 | && | 两侧 bool，结果 bool |
| 8 | \|\| | 两侧 bool，结果 bool |

同一优先级的二元运算从左到右结合。函数实参和普通二元表达式从左到右求值；&& 与 || 短路求值。整数除法向零截断。

## 强类型规则

`int` 和 `float` 的数值范围如下：

| 类型 | 范围与精度 |
| --- | --- |
| `int` | 有符号 64 位整数，精确范围为 -9223372036854775808 到 9223372036854775807（含端点） |
| `float` | IEEE 754 双精度（binary64）；最大有限正值约为 1.7976931348623157e308，最小正正规值约为 2.2250738585072014e-308，最小正非正规值约为 4.9406564584124654e-324；负值范围对称，另有正零和负零；有效精度为 53 位二进制，通常约 15～17 位十进制数字 |

浮点数不是上述区间内的每个实数都能精确表示。浮点字面量和 `str as float` 必须能解析为有限的双精度值，超出范围会报错；浮点运算仍按 IEEE 754 进行，结果可能出现无穷大或 NaN。`str` 保存 UTF-8 文本，`bool` 只有 true 和 false。不同类型之间没有隐式转换，if 和 while 的条件必须是 bool。
- array 可混放 int、float、str、bool、结构体、数组和 none。读取数组元素得到 any；print 可直接输出其中的基础值。若元素实际是结构体，可直接访问字段；若实际是数组，可直接传给 len。这两种操作会在运行时检查元素类型。
- 函数参数必须显式写类型；有返回值函数必须写返回类型，无返回值函数可以写 `-> void` 或省略返回类型。局部 auto 在编译时推断出固定类型，后续赋值仍须匹配该类型。
- 变量只在声明所在的代码块内可见；同一作用域不能重复声明，内层代码块可以遮蔽外层变量。
- 内置 print 接收一个 int、float、str、bool、none 或 any 中的可打印值，没有返回值；不能用它初始化变量或作为函数返回值。普通 `void` 函数调用也遵守此规则。
- 整数字面量按十进制读取。非负字面量只能在 0 到 9223372036854775807 之间；一元 `-` 后可直接写 `9223372036854775808`，构成最小 `int` 值 `-9223372036854775808`。单独的 `9223372036854775808` 或更大的整数常量会报编译错误。整数算术溢出和除零在运行时报错。边界用法见 [数值边界示例](../examples/numeric_bounds.tx)。

## 字符串、数组与结构体

- 字符串用双引号包围，支持 \\, \", \n、\r、\t 转义；可以用 + 拼接、用 == 和 != 比较。当前不提供按 Unicode 字符索引。
- 浮点字面量可写为 1.5、1e3、1.5e-2。不同数值类型不会自动转换；2 as float 得到 2.0，3.75 as int 得到 3。as 也支持字符串与数值的显式转换，详细规则见 [标准库说明](standard_library.md)。to_float(整数) 仍可使用。float 除以零会在运行时报错。
- 数组类型写为 array，同一数组内元素可以有不同类型。三种声明形式为 array[长度] 名称、array[长度] 名称 = [初值...] 和 array 名称 = [初值...]；前两种的长度可以是 int 表达式，运行时结果必须非负。初值数不能超过指定长度，未提供初值的位置填充 none。[] 是长度为 0 的数组。
- 数组索引从 0 开始，索引必须是 int，越界会在运行时报错。len(数组) 返回 int；数组元素实际存放数组时，也可以直接写 len(外层数组[索引])。is_none(数组元素) 可判断空位置。数组元素可用 = 赋任意受支持的值。for 遍历数组时读取一次数组表达式，并遍历当时的副本。
- 顶层用 struct 定义字段。字段按声明顺序构造，字段名必须唯一且类型有效。结构体可以作为函数参数、返回值和数组元素；字段可以是 array 或先前声明的结构体。当前不支持递归结构体。
- 数组和结构体按值传递、赋值。== 和 != 目前用于相同类型的 int、float、str、bool、none；数组和结构体暂不直接比较。print 暂不直接输出数组或结构体，可输出其元素或字段。数组元素里结构体的字段可直接读取，当前不支持直接修改该动态字段。

```tx
struct person {
    name: str
    scores: array
}

def main() -> int {
    auto user = person("Ada", [8.5, 9.0])
    user.scores[1] = 9.5
    print(user.name)
    print(user.scores[1])
    print(len(user.scores))
    return 0
}
```

更多可运行的用法见 [数据类型示例](../examples/data_types.tx)。当前尚未实现方法和自定义运算符。

## 完整示例

```tx
def sum_to(n: int) -> int {
    auto total = 0

    for i in 1..=n {
        total += i
    }

    return total
}

def main() -> int {
    print(sum_to(10))
    return 0
}
```
