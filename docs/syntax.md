# .tx 语法与类型规则

新增类型化容器 `vector<T>` 的规则与本轮支持范围见 [类型化 vector](typed_vectors.md)，示例见 [typed_vectors.tx](../examples/typed_vectors.tx)。

本文描述当前编译器已经实现的语言范围。源码使用 UTF-8；标识符目前只接受 ASCII 字母、数字和下划线，首字符不能是数字，大小写敏感。支持 # 和 // 单行注释。类、接口、抽象方法、多继承及运行时转换见 [class 说明](classes.md)。

顶层可写 import "路径.tx" 导入其他模块；路径、重复导入和命名规则见 [模块说明](modules.md)。

## 基本格式

- 代码块使用 { 和 }，缩进只用于排版。
- 语句以换行结束，也可以紧接所在代码块的右大括号；当前不使用分号。
- def（包括类方法）、struct、class、abstract class、interface、if、else、while、for 的左大括号可以与头部写在同一行，也可以在头部结束后另起一行；中间可以有空行或注释行。
- else 和 else if 可以紧接前一个右大括号，也可以另起一行；推荐另起一行。else 与后续 if 之间也允许空行或注释行。
- 圆括号和数组方括号内可以换行；结构头部与左大括号之间也可以换行。其余位置的换行会结束当前语句。

函数、参数和返回值的格式如下：

```tx
def add(left: int, right: int) -> int
{
    return left + right
}
```

返回值类型可写成 `-> int` 等具体类型；无返回值函数既可写 `-> void`，也可省略箭头和返回类型。非 `void` 函数必须在所有执行路径返回对应类型的值；`void` 函数可以自然结束，也可以使用不带表达式的 `return` 提前结束。带值的 `return` 不能用于 `void` 函数，不带值的 `return` 不能用于非 `void` 函数。程序入口仍必须是无参数、返回 int 的 `def main() -> int`。

```tx
def greet(name: str) {
    print("你好，" + name)
}

def stop_early(done: bool) -> void {
    if done
    {
        return
    }
    else
    {
        print("继续")
    }
}
```

函数支持调用自身，也支持同一模块内的函数相互调用；被调用函数可以写在调用者后面。递归需要由程序自行设置终止条件。模块之间的循环导入仍然不允许，递归结构体也尚未支持。直接递归、相互递归和无返回值函数递归见 [递归示例](../examples/recursion.tx)。

函数可在普通参数后声明 `*args` 和 `**kwargs`，各至多一个，顺序必须如此。`*args` 的类型为 `array`，`**kwargs` 的类型为 `dict`；可省略这两个参数的类型标注，也可分别写 `: array`、`: dict`。普通参数仍需显式标注类型，当前没有默认值。多余的位置实参进入 `args`，未对应普通参数名的命名实参进入 `kwargs`。调用时可写 `name=表达式`、`*数组表达式` 和 `**字典表达式`；位置实参（包括 `*`）应写在命名实参（包括 `**`）之前。实参从左到右求值；重复命名、同一参数同时接受位置和命名值、缺少必需参数，以及多余实参没有对应收集参数，都会报错。`**` 展开时字典的键必须是 `str`。显式实参按静态类型匹配；展开所得的值在运行时检查目标参数类型。对于带展开的重载调用，必须能在编译期唯一确定重载。

```tx
def show(first: int, *args, **kwargs) {
    print(first)
    print(len(args))
    print(kwargs["label"])
}

def main() -> int {
    array more = [2, 3]
    dict options = {"label": "完成"}
    show(1, *more, **options)
    return 0
}
```

同一模块内可以定义多个同名函数，只要它们的参数类型列表不同；参数名和返回类型不参与重载区分。调用时按实参的静态类型精确匹配，不能靠返回值类型选择重载，也不会为匹配重载而隐式转换 `int` 与 `float`。需要指定类型时可使用 `as` 显式转换。`main`、内置函数和结构体构造不参与函数重载。示例见 [函数重载示例](../examples/overload.tx)。

## 语句

下表中的“表达式”遵循后文的运算符规则。

| 写法 | 含义 |
| --- | --- |
| int count = 0 | 显式声明 int 变量 |
| bool ready = true | 显式声明 bool 变量 |
| float rate = 1.5 | 显式声明 64 位浮点变量 |
| str message = "你好" | 显式声明 UTF-8 字符串变量 |
| array values = [1, 2.5, "三"] | 只给初始值，长度由元素数决定 |
| array[5] values | 只给长度，5 个位置填充 none |
| array[5] values = [1, 2.5] | 给长度和部分初值，剩余位置填充 none |
| auto count = 0 | 编译时由初值推断类型 |
| count = count + 1 | 对已有变量赋值 |
| count += 1 | 对 int、float 或 str 左侧执行加法赋值；str 执行拼接 |
| count -= 1 | 对 int 或 float 左侧执行减法赋值 |
| count++ | 对 int 或 float 目标加 1，并返回更新后的值 |
| count-- | 对 int 或 float 目标减 1，并返回更新后的值 |
| left, right = values | 将数组的两个元素分别绑定或赋给变量 |
| if 条件 { ... } | 条件分支；可接多个 else if 条件 { ... }，最后可接 else { ... } |
| while 条件 { ... } | 条件循环 |
| for i in 起点..=终点 { ... } | 含终点的整数区间循环 |
| for value in values { ... } | 遍历数组元素或字典键，循环变量只读 |
| values[0] = 9 | 修改数组元素，索引从 0 开始 |
| user.age = 20 | 修改结构体字段 |
| return 表达式 | 从函数返回 |
| print(值, ...) | 输出零个或多个值，默认以空格分隔并换行 |

函数调用也可以单独作为一条语句。`=`、`+=`、`-=` 的左侧以及 `++`、`--` 的目标可以是已有变量、其数组或字典元素、结构体字段；目标必须可赋值。赋值时，先从左到右各求值一次目标中的索引，再求值右侧，最后在当前容器中定位元素并写入。数组和字典元素的静态类型是 `any`，目前不支持对它们使用 `+=`、`-=`、`++` 或 `--`。`++` 和 `--` 只接受后置写法，可以作为独立语句或参与表达式；它们先修改目标，再返回修改后的值，对 `float` 目标增减 `1.0`。`+=`、`-=` 的右侧类型必须与目标相同；`int` 的算术溢出沿用运行时错误。auto 必须有初值。区间 for 的两个边界必须是 int，且各求值一次；起点大于终点时循环零次。两种 for 的循环变量都只在循环体内可读。遍历数组或字典时，循环变量的静态类型为 any。

`a, b = values` 只允许互不相同的简单变量名。右侧必须为数组，且在运行时要求长度恰好等于左侧变量数；右侧只求值一次。已有变量按原类型赋值，新变量在当前作用域声明为 `any`。所有元素先取出并检查，再依次写入变量。

### 条件分支

`if` 后可接零个或多个 `else if`，末尾的 `else` 可省略。每个条件的静态类型必须是 `bool`，每个分支体都必须用花括号包围。条件从上到下求值，只执行第一个条件为 `true` 的分支，后续条件和分支不再执行；全部为 `false` 时执行末尾的 `else`，没有 `else` 则直接继续后面的语句。

```tx
if score >= 90
{
    print("优秀")
}
else if score >= 60
{
    print("及格")
}
else
{
    print("未及格")
}
```

各分支拥有独立的局部作用域，前一分支声明的变量在后续条件和分支中不可见。`else if` 等价于在 `else` 块中嵌套一个 `if`，沿用已有的类型检查和所有路径返回检查。可运行示例见 [else if 示例](../examples/else_if.tx)。

## 表达式

目前支持十进制整数、浮点数、双引号字符串、true/false、数组和字典字面量、变量、函数调用、索引、字段访问、圆括号和以下运算符。赋值与 ..= 不是普通表达式运算符。

| 优先级（高到低） | 运算符 | 类型要求与结果 |
| --- | --- | --- |
| 1 | 调用 ()、索引 []、字段 .、as 类型、后置 ++、-- | 访问值、显式转换或先更新目标并返回新值；++、-- 的目标必须是可赋值的 int 或 float |
| 2 | 一元 -、! | - 接收 int 或 float；! 接收 bool |
| 3 | *、/ | 两侧为相同数值类型，结果类型不变 |
| 4 | +、- | 两侧为相同数值类型；str + str 可拼接 |
| 5 | <、<=、>、>= | 两侧为相同数值类型，结果 bool |
| 6 | ==、!= | 两侧类型相同，结果 bool |
| 7 | && | 两侧 bool，结果 bool |
| 8 | \|\| | 两侧 bool，结果 bool |

同一优先级的二元运算从左到右结合。函数实参和普通二元表达式从左到右求值；&& 与 || 短路求值。整数除法向零截断。复合赋值和后置更新的可运行用法见 [更新运算符示例](../examples/update_operators.tx)。

### 自定义运算符

`struct` 和 `class` 可在类型体内用 `def operator 运算符(...) -> 类型` 声明实例运算符。`self` 是隐含的左操作数：一元 `-`、`!` 不写参数，二元 `+`、`-`、`*`、`/`、`==`、`!=`、`<`、`<=`、`>`、`>=` 恰好写一个显式类型参数。`!`、比较与相等运算符必须返回 `bool`，其他运算符必须有非 `void` 返回类型。不能使用可变参数。`struct` 中只允许这种成员方法；`class` 的运算符遵守普通方法的访问控制、继承及 `virtual`、`override` 规则。

`a 运算符 b` 只在 `a` 的静态类型及其类祖先中查找成员运算符，按参数类型选择唯一重载；不会交换左右操作数或进行隐式数值转换。虚运算符在选定重载后按实际类分派。`any` 不按运行时类型寻找运算符；需要先显式转换。`+=` 和 `-=` 使用相应的 `+`、`-` 结果赋回左值，结果必须可赋给左值类型，左值位置与右侧都只求值一次。运算符方法不会隐式复制或修改对象，是否创建新对象由方法体决定。`&&`、`||`、赋值、索引、调用、后置 `++`、`--` 暂不支持自定义重载。

单文件用法见 [运算符重载示例](../examples/operator_overloads.tx)。通过 `.txh` 导出时，声明与实现按[模块文件分工](modules.md)放置。

## 强类型规则

`int` 和 `float` 的数值范围如下：

| 类型 | 范围与精度 |
| --- | --- |
| `int` | 有符号 64 位整数，精确范围为 -9223372036854775808 到 9223372036854775807（含端点） |
| `float` | IEEE 754 双精度（binary64）；最大有限正值约为 1.7976931348623157e308，最小正正规值约为 2.2250738585072014e-308，最小正非正规值约为 4.9406564584124654e-324；负值范围对称，另有正零和负零；有效精度为 53 位二进制，通常约 15～17 位十进制数字 |

浮点数不是上述区间内的每个实数都能精确表示。浮点字面量和 `str as float` 必须能解析为有限的双精度值，超出范围会报错；浮点运算仍按 IEEE 754 进行，结果可能出现无穷大或 NaN。`str` 保存 UTF-8 文本，`bool` 只有 true 和 false。静态类型已知的不同基本类型之间没有隐式转换，if 和 while 的条件必须是 bool。
- 当右侧静态类型为 `any`、目标明确为 `int`、`float` 或 `str` 时，显式类型的变量声明、普通 `=` 赋值和函数返回会隐式执行对应的 `as` 转换。数组和字典元素读取的静态类型都是 `any`；转换按元素实际类型在运行时执行，失败时沿用 `as` 的错误。`auto` 不推断元素的实际类型，仍得到 `any`。函数实参、重载选择、运算符、复合赋值及条件表达式不使用此规则。
- `any` 可用于显式类型声明与函数签名；传入 `any` 形参仍须是静态类型为 `any` 的表达式，普通调用不会自动装箱其他类型。
- array 和 dict 可混放 int、float、str、bool、结构体、数组、字典和 none。读取元素得到 any；print 可直接输出其中的所有受支持值。若元素实际是结构体，可直接访问字段；若实际是数组或字典，可直接传给 len。这些操作会在运行时检查元素类型。
- 普通函数参数必须显式写类型；`*args` 和 `**kwargs` 的类型标注可省略。有返回值函数必须写返回类型，无返回值函数可以写 `-> void` 或省略返回类型。局部 auto 在编译时推断出固定类型，后续赋值仍须匹配该类型。
- 变量只在声明所在的代码块内可见；同一作用域不能重复声明，内层代码块可以遮蔽外层变量。
- 内置 `print()` 输出一个空行；`print(值, ...)` 按顺序输出零个或多个值，默认以空格分隔并在末尾换行。可在值后使用 `sep=str` 和 `end=str` 命名参数覆盖分隔符与结尾，不能重复，也不接受其他命名参数或 `*`、`**` 展开。每个值可以是 int、float、str、bool、none、array、dict、结构体或 any 中的这些值；静态类型已知时在编译期检查。`print` 没有返回值，不能用于初始化变量或作为函数返回值。普通 `void` 函数调用也遵守此规则。
- 整数字面量按十进制读取。非负字面量只能在 0 到 9223372036854775807 之间；一元 `-` 后可直接写 `9223372036854775808`，构成最小 `int` 值 `-9223372036854775808`。单独的 `9223372036854775808` 或更大的整数常量会报编译错误。整数算术溢出和除零在运行时报错。边界用法见 [数值边界示例](../examples/numeric_bounds.tx)。

## 字符串、数组、字典与结构体

- 字符串用双引号包围，支持 \\, \", \n、\r、\t 转义；可以用 + 拼接、用 == 和 != 比较。当前不提供按 Unicode 字符索引。
- 浮点字面量可写为 1.5、1e3、1.5e-2。静态类型为 `int`、`float` 或 `str` 的值不会自动跨类型转换；2 as float 得到 2.0，3.75 as int 得到 3。静态类型为 `any` 的值可按上面的目标类型规则转换。as 也支持字符串与数值的显式转换，以及 class/interface 引用的运行时类型转换；详细规则分别见 [标准库说明](standard_library.md)和 [class 说明](classes.md)。to_float(整数) 仍可使用。float 除以零会在运行时报错。
- 数组类型写为 array，同一数组内元素可以有不同类型。三种声明形式为 array[长度] 名称、array[长度] 名称 = [初值...] 和 array 名称 = [初值...]；前两种的长度可以是 int 表达式，运行时结果必须非负。初值数不能超过指定长度，未提供初值的位置填充 none。[] 是长度为 0 的数组。
- 数组索引从 0 开始，索引必须是 int，越界会在运行时报错。len(数组) 返回 int；数组元素实际存放数组时，也可以直接写 len(外层数组[索引])。is_none(数组元素) 可判断空位置。数组元素可用 = 赋任意受支持的值。for 遍历数组时读取一次数组表达式并记录当时的长度；遍历期间仍读取共享数组中的当前元素，新追加的元素不进入本次遍历。
- 字典类型写为 `dict`，字面量写为 `{键: 值, ...}`，空字典写为 `{}`，也可用 `dict 名称 = 初值` 声明。键必须是可哈希的 `int`、`float`、`bool`、`str` 或 `none`；值可为任意受支持的值类型。键按类型和值比较，重复键保留最后赋入的值；字典不保证遍历顺序。`字典[键]` 读取元素，键不存在时在运行时报错；`字典[键] = 值` 可以插入或更新。`len(字典)` 返回键数；`for key in 字典` 遍历进入循环时的键快照，循环变量类型为 any。允许缺键的查询、删除等操作见[字典标准库](standard_library.md#字典操作)。
- 顶层用 struct 定义字段及运算符成员。字段按声明顺序构造，字段名必须唯一且类型有效。结构体可以作为函数参数、返回值和数组元素；字段可以是 array 或先前声明的结构体。当前不支持递归结构体。
- `struct`、`class` 在 `.txh` 和配对 `.tx` 中的放置规则不同，见 [模块导入：文件分工](modules.md)。
- 数组、字典、结构体和类对象默认按引用共享：赋值、传参、返回和放入其他复合值时只复制引用，之后通过任一引用修改字段或元素，其他引用都能看到。`deep_copy(值)` 显式递归复制可达的数组、字典、结构体和类对象，返回值保持实参的静态类型；`any` 也可传入，结果保留其实际类型。复制会保留原对象图中的共享关系和循环关系，但新对象图与原图互不共享这些复合对象。类对象复制字段与运行时类型，不重新执行 `init`；新对象释放时仍按通常规则调用 `deinit`。不可变的数字、布尔值、字符串和 none 按值处理。不可达的引用环由[循环回收器](garbage_collection.md)在安全点处理，`deep_copy` 也会保留环。
- `int`、`float` 和 `bool` 的赋值直接复制值。例如 `int a = 2`、`auto b = a`、`b = 3` 执行后，`a` 仍为 `2`，`b` 为 `3`。
- `==` 和 `!=` 目前用于相同类型的 int、float、str、bool、none；复合类型暂不直接比较。print 可输出数组、字典和结构体，嵌套字符串会加引号并转义；字典输出顺序不保证，结构体保持字段声明顺序。数组元素里结构体的字段可直接读取，当前不支持直接修改该动态字段。

```tx
struct person {
    name: str
    scores: array
}

def main() -> int {
    auto user = person("Ada", [8.5, 9.0])
    user.scores[1] = 9.5
    print(user.name)
    print(user.scores[1])
    print(len(user.scores))
    return 0
}
```

更多可运行的用法见 [数据类型示例](../examples/data_types.tx)。`struct` 只支持运算符成员；`class` 的普通方法见 [class 说明](classes.md)。

## 完整示例

```tx
def sum_to(n: int) -> int {
    auto total = 0

    for i in 1..=n {
        total += i
    }

    return total
}

def main() -> int {
    print(sum_to(10))
    return 0
}
```
