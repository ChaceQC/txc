# 函数值与函数参数

本轮为普通顶层 TX 函数增加静态函数类型，使函数可作为参数、局部变量和返回值使用。函数参数可直接标注为 `fn`；编译器根据该参数在函数体内的调用实参及调用结果所处的已知类型位置确定签名，并在调用方检查传入函数是否精确匹配。需要显式标注时也可写 `fn(参数类型, ...) -> 返回类型`；无参数写 `fn() -> 类型`，无返回值写 `fn(...) -> void`。参数名不是函数类型的一部分。

```tx
def twice(value: int) -> int
{
    return value * 2
}

def increase(value: int) -> int
{
    return value + 1
}

def apply(value: int, operation: fn) -> int
{
    return operation(value)
}

def main() -> int
{
    print(apply(21, twice))
    print(apply(21, increase))
    return 0
}
```

函数签名中的参数与返回值使用语言已有的合法类型，不预设某几种基础类型；`void` 与普通函数一样只用于返回值。省略签名的 `fn` 在 `return operation(...)`、有显式类型的变量初值或赋值右侧、独立的无返回值调用中推断返回类型；签名无法由这些位置确定时，应写完整函数类型。函数名在值位置表示该函数的地址；它必须对应一个未重载、非外部接口的普通顶层 TX 函数。重载函数不能直接取值，可写一个签名确定的包装函数。回调变量的调用目前只接受位置实参，个数与类型必须精确匹配；不接受命名实参、`*` 或 `**` 展开。函数值没有捕获环境，本轮不提供 lambda、闭包、绑定对象方法或运行时函数名查找。

函数值在当前进程内有效，无需显式释放。它不进入 `any`、异构数组/字典、结构体或类字段；这些边界需要额外的运行时表示与生命周期规则，暂不引入。普通函数仍按现有重载规则直接调用。函数值调用的目标只可能是已静态检查过的同签名函数，调用时沿用现有错误传播规则。

独立用法见[示例](../examples/function_values.tx)。2026-09-26 已构建编译器，并在用户允许的少量定向验证中编译、运行该示例：同一个 `apply` 分别接收 `twice` 和 `increase`，输出 `42`、`22`；字符串回调输出 `TX!`，程序退出码为 0。另一个[静态类型不匹配用例](../tests/functions/function_value_type_error.tx)按预期在传入 `fn(str) -> int` 时报告 `apply(int, fn(str)->int)` 无匹配重载。未运行全量回归。
