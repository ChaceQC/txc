# 函数值与函数参数

本轮为普通顶层 TX 函数增加静态函数类型，使函数可作为参数、局部变量和返回值使用。函数参数可直接标注为 `fn`；编译器根据该参数在函数体内的调用实参及调用结果所处的已知类型位置确定签名，并在调用方检查传入函数是否精确匹配。需要显式标注时也可写 `fn(参数类型, ...) -> 返回类型`；无参数写 `fn() -> 类型`，无返回值写 `fn(...) -> void`。参数名不是函数类型的一部分。

```tx
def twice(value: int) -> int
{
    return value * 2
}

def increase(value: int) -> int
{
    return value + 1
}

def apply(value: int, operation: fn) -> int
{
    return operation(value)
}

def main() -> int
{
    print(apply(21, twice))
    print(apply(21, increase))
    return 0
}
```

函数签名中的参数与返回值使用语言已有的合法类型，不预设某几种基础类型；`void` 与普通函数一样只用于返回值。省略签名的 `fn` 在 `return operation(...)`、有显式类型的变量初值或赋值右侧、独立的无返回值调用中推断返回类型；签名无法由这些位置确定时，应写完整函数类型。顶层函数名可作为无捕获函数值；它必须对应一个未重载、非外部接口的普通顶层 TX 函数。重载函数不能直接取值，可写一个签名确定的包装函数。回调变量的调用只接受位置实参，个数与类型必须精确匹配；不接受命名实参、`*` 或 `**` 展开。

`bind(function, prefix_arg, ...)` 按值捕获函数的前若干参数，返回剩余参数签名的闭包。普通赋值共享复合对象引用；要隔离修改，可先 `deep_copy` 再捕获。每次调用临时借用闭包拥有的捕获值，调用结束即结束借用；没有可逃逸的 `&` 捕获。闭包可作为函数参数、返回值或字段使用，也可显式进入 `any` 并按完整 `fn(...) -> ...` 签名恢复。闭包中捕获的对象参与循环回收，异常使用原错误类别沿调用链传播。比较器、排序和线程调用方另有各自的纯度及跨线程限制。`bind` 不引入 lambda 块语法，函数目标及捕获前缀均在编译期确定类型。

函数值现在持有运行时环境，普通赋值共享闭包及其捕获，`deep_copy` 复制捕获对象图。单线程程序中调用与释放遵守普通复合值的生命周期。旧无捕获顶层函数的调用形式保持不变；重新构建的标准库桥接代码使用同一函数值 ABI。

独立用法见[示例](../examples/function_values.tx)。2026-09-26 已构建编译器，并在用户允许的少量定向验证中编译、运行该示例：同一个 `apply` 分别接收 `twice` 和 `increase`，输出 `42`、`22`；字符串回调输出 `TX!`，程序退出码为 0。另一个[静态类型不匹配用例](../tests/functions/function_value_type_error.tx)按预期在传入 `fn(str) -> int` 时报告 `apply(int, fn(str)->int)` 无匹配重载。未运行全量回归。

## 2.5 实施记录

- **代码：** `bind` 以静态签名捕获前缀实参，生成专用 LLVM 回调包装函数；函数值统一持有带目标和环境的运行时句柄，间接调用仍使用类型明确的形参与返回值。捕获按普通赋值语义持有；调用期间从环境取临时拥有型值供回调使用，不暴露可逃逸栈借用。闭包可作为返回值、字段或 `any` 值，接入 `deep_copy` 与循环回收对象图。已有顶层 `fn` 和标准库 TX 桥接源码已按同一 ABI 重建。
- **构建：** `scripts/build.ps1` 在 Windows x64 成功生成编译器、标准库静态库及兼容清单。
- **定向验证：** 原[函数值示例](../examples/function_values.tx)重新编译运行，仍输出 `42`、`22`、`TX!`；[闭包示例](../examples/closures.tx)覆盖嵌套绑定、标量/字符串/复合值/函数值捕获、共享与 `deep_copy`、字段和 `any` 恢复、返回闭包。`tests/stdlib/closure_module/main.tx` 跨 `.txh` 输出 `12`，`closure_error.tx` 捕获原 `runtime_error`，`closure_cycle.tx` 对闭包与字典形成的引用环进行 `deep_copy` 并输出 `6`，错误捕获类型在源码位置报告中文诊断。未运行全量套件。
- **边界与验收：** 显式 `&` 捕获和 lambda 块语法未引入；受控借用只发生在一次同步调用内部，闭包始终拥有捕获值。闭包跨线程传递仍须 2.6 的静态约束及后续并发运行时。当前证据限 Windows x64。
