# 静态类型借用路径修复

2026-09-30，第一批实施范围：文本字面量字典查询、serde 输入借用、静态字符串字段长度读取、局部类转换借用。不改变语言语法、公开接口和错误顺序。

## 实现约束

- `dictionary.get/contains` 的字符串字面量参数直接传递 UTF-8 字节地址和长度，包含空串、中文和内嵌零字节。接收者先求值；变量键与有副作用的键表达式保持现有路径。
- JSON/CBOR serde 入口只在调用期间读取输入，不保存借用地址、不回调用户代码。位置参数通过已有调用效果与所有权标记借用，临时结果仍按原所有权释放；现行 serde 语法仍只接受单个位置实参。解码失败回退、版本、重复字段与未知字段处理不变。
- 首先覆盖 `len(局部对象.str字段)`：从静态字段槽位直接借用字符串读取长度，保留类字段初始化检查；临时接收者保持原路径。其他字段文本操作和嵌套接收者后续扩展。
- 类转换仅借用外层作用域的稳定源局部。整个函数中源和目标均不得重新绑定、移动或同名遮蔽；同层源保持拥有的结果。非异常模式的显式返回从外层开始清理，因此该模式下含显式返回的函数保守回退。异常模式按内层到外层清理，返回值仍在返回边界克隆。保留原位置的类型检查，复用源缓存视图，不把可能失败的检查提到循环外。
- 只对实际生成的借用转换声明取消无分配、无用户回调的声明后安全点；调用与可能分配的其他路径保持现有策略。

## 验证

使用 `scripts/check_static_borrowing.py --baseline` 在修改前固定两组原基准中的相关函数，构建旧程序；完成实现和整包构建后运行 `--check` 检查目标 IR 与相关语义，再用 `--measure` 做同机新旧交替测量。原始样本记录在独立目录，不覆盖已有全量报告。

第一批已实现并完成定向验证。最终 5 轮交替测量中，文本键查询、类转换、短文本 serde、长文本 serde 的耗时分别下降 70.36%、93.92%、17.26%、4.81%。详细样本、边界与产物指纹见[第一批修复记录](../benchmarks/static_borrowing_2026-09-30/README.md)。这些数字是 TX 新旧程序之比，不是重新测量的 TX/C++ 倍率。

本批不包含跨函数结构体静态存储、引用字段内嵌、固定模板合并、专用 serde、深拷贝身份表和 GC 算法改动。`format_dynamic` 的历史倍率应解释为局部固定模板格式化，不能代表真正动态模板。
